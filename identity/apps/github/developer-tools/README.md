# GitHub App: tupynambalucas-developer-tools (Tier 3)

## Finalidade e Escopo Operacional

Este aplicativo opera no **Plano de Desenvolvedor e Linha de Comando** (*Developer & CLI Plane*). Suporta a autenticação da CLI corporativa em Go (`tl` / `gh tl`) e interações locais via OAuth Device Flow, garantindo zero armazenamento de chaves `.pem` nas estações de trabalho de desenvolvedores.
