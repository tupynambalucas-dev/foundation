# Conformidade Legal e Políticas de Privacidade Centralizadas

Este diretório mantém os termos jurídicos e a política de privacidade canônica corporativa da organização `tupynambalucas-dev`.

## Arquitetura de Publicação

1. **Fonte Única da Verdade**: Os arquivos `privacy-policy.html` e `terms-of-service.html` mantidos aqui são a referência legal canônica para todas as aplicações, ferramentas e integrações sob o domínio `tupynambalucas.dev`.
2. **Distribuição Pública**: São sincronizados e distribuídos publicamente via Cloudflare Workers com Static Assets através do portal `apps.tupynambalucas.dev` nas rotas:
   - `https://apps.tupynambalucas.dev/privacy`
   - `https://apps.tupynambalucas.dev/terms`
3. **Conformidade Google OAuth**: Atende integralmente aos requisitos da *Google API Services User Data Policy* e validação de marca (*Brand Verification*), declarando expressamente a proibição de compartilhamento a terceiros e de treinamento de modelos de inteligência artificial sobre dados privados de usuários.
