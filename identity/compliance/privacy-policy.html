Política de Privacidade e Tratamento de Dados

Organização Responsável: tupynambalucas-dev (Lucas Tupynambá)
Domínio Autorizado: tupynambalucas.dev
Última Atualização: 2026-11-20

Resumo da Política: Os aplicativos, ferramentas de linha de comando e utilitários desenvolvidos sob o domínio tupynambalucas.dev (incluindo clientes de sincronização de arquivos Rclone e agentes de integração de produtividade) acessam dados de contas de usuários estritamente para executar as funcionalidades operacionais solicitadas de forma transparente e segura. Nenhum dado é vendido, transmitido a terceiros ou utilizado para treinamento de modelos de inteligência artificial.

1. Escopo de Aplicação

Esta Política de Privacidade aplica-se universalmente a todos os serviços, integrações de software, ferramentas CLI e aplicativos OAuth autenticados sob o domínio tupynambalucas.dev, incluindo:

  • Rclone Windows Desktop Client (Sincronização de unidades virtuais Google Drive via WinFsp para contas pessoais e corporativas).
  • Workspace & AppSheet Automation Services (Agentes de manipulação de relatórios, planilhas e documentos corporativos).
  • Developer Tools & Extensions CLI (Utilitários operacionais locais).

2. Dados Coletados e Finalidade do Tratamento

Nossos aplicativos acessam exclusivamente as informações autorizadas pelo usuário durante a tela de consentimento OAuth do Google:

  • Arquivos e Pastas do Google Drive (drive / drive.file): O aplicativo Rclone acessa arquivos única e exclusivamente para leitura, gravação e montagem de discos locais no sistema operacional do usuário. Os arquivos trafegam de forma cifrada diretamente entre o cliente local e os servidores da Google LLC.
  • Planilhas e Documentos do Google Workspace (spreadsheets / documents): Utilizados para leitura e escrita de registros parametrizados requisitados explicitamente pelo usuário.

3. Conformidade com a Google API Services User Data Policy

O uso e a transferência de informações recebidas das APIs do Google para qualquer outro aplicativo seguirão estritamente a Google API Services User Data Policy, incluindo os requisitos de Limited Use:

  • Sem Comercialização: Nenhuma informação pessoal ou de arquivos de usuários é compartilhada, alugada ou vendida para terceiros.
  • Sem Treinamento de IA: Os dados dos usuários não são utilizados para treinar modelos generalistas ou proprietários de inteligência artificial ou aprendizado de máquina.
  • Armazenamento Hermético: Chaves de API e tokens de atualização (refresh tokens) residem exclusivamente no dispositivo local do usuário sob permissões restritas de sistema de arquivos ou em cofres de segredos criptografados (Infisical).

4. Revogação de Acesso e Exclusão de Credenciais

O usuário mantém controle integral sobre suas autorizações. O acesso pode ser rescindido a qualquer momento:

  1. Acessando a página de segurança oficial do Google: myaccount.google.com/permissions.
  2. Localizando o aplicativo correspondente (ex.: Rclone Windows Client) e clicando em Remover Acesso.
  3. Localmente, o usuário pode excluir o arquivo de configuração de credenciais a qualquer momento (ex.: rclone config).
