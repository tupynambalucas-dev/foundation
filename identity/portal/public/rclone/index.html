Rclone Windows & WSL Desktop Client

Aplicação Desktop para Integração, Montagem e Backup Multi-Contas do Google Drive.

Identificação da Aplicação

Desenvolvedor Responsável: Lucas Tupynambá Organização: tupynambalucas-dev Domínio Autorizado: tupynambalucas.dev

O Rclone Windows Desktop Client é uma aplicação de integração desktop pessoal e corporativa projetada para sincronizar, fazer backup e montar pastas remotas do Google Drive como unidades virtuais de sistema de arquivos locais no Windows e no subsistema Linux WSL2 através do WinFsp.

Finalidade do Acesso às APIs do Google

Este aplicativo utiliza autenticação OAuth 2.0 oficial (tipo Desktop Application) solicitando acesso à API do Google Drive (escopo https://www.googleapis.com/auth/drive) com as seguintes finalidades exclusivas:

  • Montagem de Unidades Virtuais Locais: Montar discos virtuais nas letras H: (Pessoal), E: (Organização), L: (Secundário) e R: (Backup) no Windows Explorer para navegação transparente de arquivos.
  • Execução de Backups Profissionais: Realizar rotinas de backup incremental, snapshots com retenção histórica (--backup-dir) e espelhamentos bidirecionais (rclone bisync).
  • Transferências Diretas Nuvem-para-Nuvem: Transferir arquivos entre contas pessoais e organizacionais nos próprios datacenters do Google sem download local via --drive-server-side-across-configs.

Privacidade, Segurança e Armazenamento Hermético

Conformidade Rigorosa com a Google API Services User Data Policy:

  • Sem Venda ou Compartilhamento: Nenhum dado, metadado ou conteúdo de arquivos é compartilhado, alugado, cedido ou vendido para terceiros.
  • Sem Treinamento de Inteligência Artificial: As informações e arquivos acessados pelo aplicativo nunca são utilizados para treinar modelos de inteligência artificial ou aprendizado de máquina.
  • Criptografia e Isolamento Local: Os tokens de acesso e de atualização (refresh tokens) residem exclusivamente no computador local do usuário dentro do arquivo protegido de configuração do Rclone ou em cofres de segredos criptografados.

Como Revogar Autorizações

O usuário pode revogar o acesso deste aplicativo a qualquer momento:

  1. Acessando a página de segurança de contas do Google: myaccount.google.com/permissions.
  2. Localizando o aplicativo Rclone Windows Client e clicando em Remover Acesso.
  3. Localmente no computador, excluindo a seção do remote correspondente via comando rclone config.
