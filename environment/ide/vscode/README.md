# VS Code Domain Slice (\`@tupynambalucas-dev/foundation-environment/vscode\`)

Enterprise governance of Visual Studio Code profiles, settings, extension matrices, and cross-platform keybindings.

## 1. Structure

- **`profiles/`**: Pre-configured role profiles. Importable via `code --profile <name>`.
- **`shared/`**: Common organizational settings and extension recommendation templates.
- **`matrix/`**: Extension compatibility list with platform support indicators.
- **`keybindings/`**: Canonical keyboard shortcut mappings for Windows, macOS, and Linux.
