# IDE Subdomain Governance (\`@tupynambalucas-dev/foundation-environment/ide\`)

Modular directory partitioning developer configurations across supported IDEs.

## 1. Supported Editors

- **`vscode/`**: Active official standard for development within the organization.
- **`jetbrains/`**: Extension slice for IntelliJ, WebStorm, and GoLand.
- **`neovim/`**: Extension slice for Lua / LazyVim.
